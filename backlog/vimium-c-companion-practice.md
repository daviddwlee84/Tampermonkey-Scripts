# Vimium C Companion 任務式練習卡

Status: deferred
Priority / effort: P3 / L
Last reviewed: 2026-09-09

## 背景與目前決策

v0.1 預設是分類小抄與可閱讀的操作流程，完整參考可另外展開。使用者把「一步步任務卡」與「常駐完整双欄總表」留待日後；後者是 TODO 中独立的 P3 / M 項目。

## 預期能力

從連結開啟、搜尋、選文複製到分頁操作，提供少量可重複練習的任務；步驟依 Companion 設定檔鍵位預覽顯示。記住已完成項目與下次練習位置，允許手動重設。

## 實作前需要決定

- 以目前任意網頁練習，還是提供可預測內容的專用練習頁。
- 是否需要分階段／重複練習與匯出進度；先從少量任務驗證價值。
- 在沒有權威原生命令回饋的前提下，完成確認採使用者手動按鈕；不能因為觀察到 `f` 或 `yv` 就自動判定成功。
- 匯入設定部分解析、未綁定命令時，步驟必須顯示缺口，不能默默換成原生預設。

## 接續步驟

先做「搜尋後選取一個詞並複製」與「開啟連結後恢復分頁」兩張原型，測試使用者能否跟著個人鍵位完成，再擴大任務集。互動狀態研究另見 [橋接研究](vimium-c-companion-bridge.md)。
